# ⛏️ Keeper Miner

داشبورد شخصی ماینینگ با CPU، برای سیستم خودت.

## شروع سریع

### ویندوز ۱۱
1. **Python** نصب کن: https://www.python.org/downloads/ (تیک "Add to PATH")
2. کل پروژه رو دانلود کن
3. روی `start.bat` دابل کلیک کن
4. مرورگر خودش باز می‌شه → `http://localhost:5000`
5. آدرس ولت رو ببین، CPU رو روی ۳۰٪ بذار، **شروع**

### لینوکس / WSL2
```bash
chmod +x start.sh
./start.sh
